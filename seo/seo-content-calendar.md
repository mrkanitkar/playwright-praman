## Internal Linking Strategy

Every blog post should include:

1. At least 3 links to documentation pages
2. At least 1 link to another blog post (once more exist)
3. A "Get Started" CTA at the end linking to `/docs/guides/getting-started`
4. An npm install command block
5. A GitHub star ask

## SEO Checklist for Each Post

- [ ] Title includes primary keyword
- [ ] First paragraph includes primary + secondary keywords naturally
- [ ] Meta description is 150-160 chars with call-to-action
- [ ] H2 headings include keyword variations
- [ ] At least 1 image with descriptive alt text
- [ ] At least 3 internal links to docs
- [ ] Code examples are syntax-highlighted
- [ ] Reading time shown (Docusaurus does this automatically)
- [ ] Tags include relevant keywords
- [ ] Author info is complete in `authors.yml`
